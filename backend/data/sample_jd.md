# Backend Engineer

We are hiring a Backend Engineer to build and maintain REST APIs and data services for InterviewLens.

## Requirements

- Strong **Python** (3.11+) for services and tooling
- Experience designing and shipping **HTTP APIs** (FastAPI or similar)
- Comfortable with **SQL** and relational schema design (SQLite/Postgres)
- Familiarity with async jobs, file uploads, and structured logging

## Nice to have

- Local LLM integration (Ollama) for structured analysis
- Speech-to-text pipelines (Whisper) and speaker diarization

## Role

You will own backend endpoints for session setup, transcript editing, and evidence-backed hiring reports. Work closely with frontend on a local-first interview studio.
